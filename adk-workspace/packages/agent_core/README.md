# Security Guard Agent

## Como Rodar

1. __Exportar a Service Account do seu projeto com o Vertex AI habilitado.__

2. __Renomear o Json exportado para `credentials.json`.__

3. __Colocar o json renomeado no mesmo nível de main_agent.py__

4. __Rodar o env.sh: source env.sh__

5. __Executar o agente: uv run main_agent.py__
